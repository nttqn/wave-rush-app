# CLAUDE.md: Wave Rush

Flutter "wave" arrow game (hold = rise at 45°, release = fall). Landscape, Android via CI only
(`android/`, `web/` gitignored and regenerated by `flutter create` in CI, same pattern as the other games
in this series). Package `com.trungsmail.wave_rush`.

## Architecture
- `lib/game/`: **pure Dart**, no Flutter imports. Unit-tested in `test/level_test.dart`.
  - `level_data.dart`: world geometry (y-up, height 10 units), wall polylines, spikes, saws, portals,
    `collides()`. All lists stay sorted by x; lookups are binary searches (endless keeps appending).
  - `level_generator.dart`: `LevelBuilder`, which builds section by section: first a **safe path** (slopes exactly
    ±wave slope, min segment length = reaction time), then walls/hazards placed only with clearance from
    it. That's why every level is beatable by construction.
  - `wave_engine.dart`: `WaveEngine`, fixed 1/120 s step, and `LevelSolver`, an exhaustive hold/release
    reachability check that uses the *same* step + `collides()`. If you change physics, change both
    in lockstep, or the solver tests stop meaning anything.
  - `levels.dart`: the 12 `LevelDef`s (seed + difficulty ramp + speed + palette + music). **Changing a
    seed, or any generator logic, changes the level geometry**, and players' saved best % would then
    refer to a different level. Fine pre-launch; after launch, only add new levels.
- `lib/ui/game_painter.dart`: draws everything in world units after one canvas flip.
- `lib/screens/game_screen.dart`: Ticker → engine, Listener pointer-set for hold, keyboard
  (Space/↑/W, Esc = pause) for web, `PopScope` back = pause toggle.
- Home screen background is an endless run flown by an autopilot following `LevelBuilder.safePathYAt`.

## Audio
`tool/gen_audio.js` (Node) synthesizes everything in `assets/audio/`. There are no third-party sounds.
`SoundService.init()` must stay unawaited in `main()`.

## Verification done

behaviour). The web build was walked through in Playwright at 844x390 @3x: home → level select → play →
crash → auto-restart (Attempt 2) → pause.
